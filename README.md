# Deadwax

Deadwax is an interactive, web-based record player experience inspired by analog vinyl culture. The project explores how physical objects and behaviors—such as spinning records, tonearms, and album selection—can be translated into a digital interface. Music content is powered by the Spotify API.

## Overview
This project focuses on interaction design, visual feedback, and motion to create a tactile-feeling UI using modern front-end fundamentals. Deadwax emphasizes clarity, affordances, and polish while integrating real-world music data through an external API.

## Features
- Interactive record player interface
- Album and track data sourced from the Spotify API
- Dynamic UI updates based on selected music
- CSS-driven animations and transitions
- JavaScript-powered interaction and state logic
- Design inspired by physical media and analog systems

## Built With
- HTML
- CSS
- JavaScript
- Spotify Web API

## Goals
- Explore physical-to-digital metaphors in UI design
- Practice API integration in a front-end project
- Build expressive micro-interactions and motion
- Create a polished, portfolio-ready experience

## Future Improvements
- Improved accessibility and keyboard interactions
- Better state management for playback and UI
- Expanded browsing and filtering options
- Mobile-specific interaction refinements

## Notes
This project was created as a portfolio piece to demonstrate UI/UX thinking, interaction design, and front-end development skills while working with a real-world API.

## Spotify API Disclaimer

Deadwax uses the Spotify Web API to retrieve music-related data such as album information, artwork, and track details. Playback behavior and content availability are subject to Spotify’s platform limitations and terms of service.
